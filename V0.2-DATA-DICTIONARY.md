# SEG Dashboard DG — V0.2 Data Dictionary

## Sources
- BD_TECNICO_COMERCIALE_2025.xlsx
- BD_TECNICO_COMERCIALE_2026.xlsx

## Canonical dimensions
- agencies: Yimbaya, Matoto, Kountia, Wanindara, Cimenterie, Ratoma, Dixinn, Kaloum, Matam
- client_types: Domestique, Commerce, Industrie, Administration, Autres ADM, Agent SEG, Installation SEG, Bornes Fontaines

## Facturation
Granularite: mois + agence + type client.
Les totaux absents sont recalcules uniquement lorsque les composantes sont disponibles.
Les valeurs Excel non fiables ou absentes restent NULL; aucune valeur source n'est inventee.

## Technique
Granularite: mois + agence.
Rendement = volume_consomme / volume_produit.
Ratio facturation = volume_facture / volume_produit.
Les rendements hors [0,1] sont conserves et signales dans data_quality_issues.

## Recouvrement
Granularite: mois + agence + type client.
Taux brut = montant_regle / montant_facture_et_penalite.
Taux actualise = montant_regle_actualise / montant_facture_et_penalite.
Evolution = taux_actualise - taux_brut lorsque les deux existent.

## Qualite
Les imports sont journalises dans data_imports. Les anomalies sont journalisees dans data_quality_issues.
Le fichier 2025 contient notamment des periodes/donnees partielles et des formules historiques non exploitables; elles ne sont pas remplacees silencieusement.
